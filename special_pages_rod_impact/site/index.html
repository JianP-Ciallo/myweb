网页端能展示什么

这里是可部署到 GitHub Pages 的静态展示页，用于说明场景、参数和工作流。 它不依赖服务器，也不会尝试在浏览器中运行 Python。

完整功能在哪里运行

模型生成、MCP 工具、workspace 文件写入、LS-PrePost 启动和预览导出都在用户本机运行。 下载包解压后使用 start_web_app.cmd 启动。

GitHub Pages 功能边界

GitHub Pages 只能托管 HTML、CSS、JavaScript 和下载文件，不能运行 Python 后端， 不能启动 MCP Server，不能写入你的本地项目目录，也不能调用本机 LS-PrePost。

本地完整运行步骤

  1. 下载 lsprepost-mcp-special-rod-impact.zip。
  2. 解压到本机普通目录，不要直接在压缩包内运行。
  3. 双击 start_web_app.cmd。
  4. 按页面提示设置本机 lsprepost*.exe 路径。
  5. 在本地 Web App 中生成、校验并打开 LS-PrePost 预览。
